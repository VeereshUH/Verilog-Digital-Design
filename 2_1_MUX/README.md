# 2:1 Multiplexer (MUX)

## Aim
To design a 2:1 multiplexer using Verilog HDL.

## Logic
- When `sel = 0`, output is `a`.
- When `sel = 1`, output is `b`.

## Implementations
1. Dataflow Modeling
2. Structural Modeling
3. Behavioral Modeling

## Testbench
A testbench is used to test all input combinations and verify the output.

## Tools Used
- Verilog HDL
- EDA Playground
