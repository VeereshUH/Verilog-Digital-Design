# 4-to-1 Multiplexer using Verilog

## Description
A 4-to-1 Multiplexer is a combinational digital circuit that selects one of four input signals based on two select lines and produces a single output.

## Design
Implemented using **Structural Modeling** with NOT, AND, and OR gates.

## Files
- `design.sv` – Verilog implementation of the 4-to-1 Multiplexer.
- `testbench.sv` – Testbench to verify the functionality of the multiplexer.

## Simulation
Simulated using EDA Playground.
